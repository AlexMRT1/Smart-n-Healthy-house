# Tareas

Cada cambio cabe en un modulo y se comprueba con `npm test`.

- Sensores e incidentes: `API/server/domain`
- Servidor de la casa: `API/server/server.js`
- Registro: `API/server/auth0/server`
- Verificacion: `API/server/auth0/sign-in/verification`
- Asistente: `API/Gemini/domain`
- Clima: `API/Accuweather`
- Tablero: `WWW/Dashboard/scripts/logic.js`

Comandos: `npm ci`, `npm test`, `npm run lint`, `npm run build`, `npm start`.
